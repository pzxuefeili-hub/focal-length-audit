# Gap 笔记（中文对照版）

> 本文件是 `GAP_NOTE.md` 的中文对照，仅供本人理解用；正式存档以英文版为准。

## 前人工作分三条线，每条线都停在了半路上

**第一条线——控制类研究：给模型"加装置"让它听话。**
Yuan 等人（Generative Photography，CVPR 2025）先证明现成的生成模型没法按焦距要求做出场景一致的视场变化，然后提出自己的训练方法解决它。Fang 等人（Camera Settings as Tokens，SIGGRAPH Asia 2024）先诊断出原因——CLIP 文本编码器对数字式相机参数几乎瞎猜——然后用 LoRA 加专门的相机词元修复。Bernal-Berdun 等人（PreciseCam，CVPR 2025）用 ControlNet 直接控制 roll/pitch/vFoV/畸变，明确把"提示词工程"当基线打败。**三篇的形状一模一样：先证明纯提示词失败，然后造一个补救装置。没有一篇停下来测量"失败本身有多严重"**——模型实际生成的图离请求的焦距差多远？ across 不同措辞、不同模型、不同编码器家族，没人量化过。

**第二条线——测量类研究：几何仪器已经有了，而且可信。**
Veicht 等人（GeoCalib，CVPR 2024）把单图相机内参估计做成了带不确定度的几何优化。Zhu 等人（Tame a Wild Camera，NeurIPS 2023）零样本标定 4 自由度内参（Apache-2.0 协议，本项目已确认可用）。GenSpace（NeurIPS 2025）示范了"怎么证明几何指标和人一致"：用 900 张人工标注图验证，几何管线与人类的符合率 76%，而最强的通用视觉语言模型只有 56%。**但 GenSpace 测的是笼统的"空间感知"，没有人把这类仪器专门对准"焦距语言依从"这一个量。**

**第三条线——语言类研究：为什么提示词可能失败、措辞研究怎么做。**
Paiss 等人（Teaching CLIP to Count to Ten，ICCV 2023）证明数字是 CLIP 文本空间里的盲区——这正是焦距措辞失灵的最可能机理，而 CLIP 编码的模型（如 SDXL）原样继承了这个盲区。Liu & Chilton（CHI 2022）研究提示词怎么写才能出好图，开创了"语域"传统：数字式（"24mm"）、描述式（"wide-angle"）、体裁式（"street photography"）是用户表达意图的不同说法——**但语域从来没被当作"物理指令"来比较过。**

## 空档（gap）一句话

**没有人用几何验证过的测量仪器，量化过开箱即用、未经微调的文生图模型（SDXL / SD3.5 / FLUX，恰好覆盖 CLIP、CLIP+T5、T5 三种编码器家族）对数字式、描述式、体裁式三种焦距措辞的依从程度。**

控制类研究把提示词失败当动机、测完就过；测量类研究从没把仪器对准语言；语言类研究从没把措辞和实测几何挂钩。本项目就站在三者交会的空档上：先造尺子（用已知焦距的实景把标定仪器验证合格，rung A–D），再量每个模型、每种语域的预注册依从斜率 β。β ≈ −1 说明模型像真镜头一样听话；β ≈ 0 说明那个数字只是装饰。
